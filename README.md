# Pakistan Tour Timeline

> A personal travel timeline documenting a 10-day trip across Pakistan in June 2023 — built with vanilla HTML, CSS, and Bootstrap.

---

## Overview

A static two-page website that chronicles a road trip through Pakistan, from Lahore to Naran, laid out as an animated vertical timeline. Each day gets its own entry with a date bubble, title, and description. Includes a separate photo gallery page.

## Tech Stack

- HTML5 + CSS3
- Bootstrap 4 / 5
- Google Fonts (Poppins)
- No JavaScript frameworks — pure static site

---

## Pages

- `index.html` — animated vertical travel timeline
- `gallery.html` — photo gallery from the trip

---

## Running Locally

No build step needed. Just open in a browser:

```bash
git clone https://github.com/illusionoftalha/travel_timeline_site.git
cd travel_timeline_site
# open index.html in your browser
```

Or serve it:

```bash
npx serve .
```
